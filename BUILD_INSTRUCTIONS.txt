SHOP MANAGER APP - PRODUCTION BUILD INSTRUCTIONS
================================================================================

QUICK START
-----------

To create a production build and compress your project, run ONE of these commands:

  Option 1 (Recommended - Python):
  $ python3 /project/finalize-build.py

  Option 2 (Node.js):
  $ node /project/build-complete.js

  Option 3 (Bash):
  $ bash /project/build-production.sh


WHAT GETS CREATED
------------------

Running any of the above commands will:

1. Execute: npm run build
   - Compiles React + TypeScript code
   - Optimizes CSS and JavaScript
   - Creates /project/dist/ directory with production files

2. Create: /project/shop-manager-app.zip
   - Contains the entire project
   - Includes: dist, src, node_modules, configs, etc.
   - Size: Typically 300-500 MB (with compression)

  ✓ .gitignore


DEPLOYMENT
----------

After the zip is created:

1. Download: /project/shop-manager-app.zip

2. Extract on your server:
   $ unzip shop-manager-app.zip

3. Deploy the dist/ folder to your hosting:
   - Upload dist/* to your web server
   - Or use: npm run preview (for testing)

4. For production servers:
   - Copy dist/ contents to your CDN/web server
   - Configure your server to serve index.html for all routes


HELPER SCRIPTS CREATED
----------------------

1. finalize-build.py
   - Complete Python script with detailed output
   - Handles build + zip creation
   - Best for: Most reliable, detailed logging

2. build-complete.js
   - Node.js script using archiver module
   - Good for: Node.js environments

3. create-zip.js
   - Pure Node.js zip creation (no build)
   - Good for: Zipping existing builds

4. build-production.sh
   - Bash script for Unix/Linux
   - Good for: Shell environments


TROUBLESHOOTING
---------------

Build fails?
  - Check: npm install
  - Check: node --version (v18+ recommended)
  - Check: npm run lint

Zip creation fails?
  - Check: python3 --version
  - Check: zip command available (which zip)
  - Check: Disk space (df -h)

Missing files in zip?
  - Check: All source files exist
  - Check: File permissions
  - Try: Alternative script
